# 卡牌大师战斗助手

这是一个面向 Fabula Ultima「卡牌大师」职业的网页战斗助手，用来在冲突场景中管理牌堆、手牌、弃牌堆和职业技能操作。

第二阶段已支持多人房间同步：主持人和玩家打开同一个房间链接，会看到同一份牌局状态；服务器重启后会从 SQLite 恢复房间数据。

出于安全考虑，房间不能通过浏览器随意创建。管理者必须先在 `rooms.json` 中定义允许访问的房间 ID。

## 当前功能

- 30 张卡牌大师牌堆管理：4 花色各 1-7，加 2 张百搭牌。
- 冲突开始时自动洗牌并抽取 5 张初始手牌。
- 手牌选择、弃牌堆展示、牌堆不足时洗入弃牌堆。
- 主动提示当前手牌可达成的组合。
- 提示当前选中卡牌的组合效果。
- 支持普通技能流程：
  - 豪赌乾坤
  - 风险对冲
  - 魔法卡牌
  - 时运再来
  - 陷阱卡牌
- 支持角色等级，并自动应用 20 级 / 40 级的组合伤害加成。
- 操作记录卡按顺序生成，支持按最新操作逐步撤销。
- 支持房间 URL、WebSocket 实时同步和 SQLite 持久化。

## 使用方式

安装依赖：

```bash
npm install
```

启动服务：

```bash
npm start
```

默认访问地址：

```text
http://localhost:6021
```

房间地址示例：

```text
http://localhost:6021/room/my-table
```

其中 `my-table` 必须已经写在 `rooms.json` 中，例如：

```json
{
  "rooms": [
    {
      "id": "my-table",
      "name": "默认牌局"
    }
  ]
}
```

把同一个房间链接发给玩家即可同步同一牌局。也可以使用 `?room=` 参数，但同样必须是 `rooms.json` 中存在的 ID：

```text
http://localhost:6021/?room=my-table
```

数据会保存到 `data/card_tool.sqlite`。只要保留这个文件，服务重启后可以恢复之前的房间状态。

## 说明

本工具只负责卡牌大师的牌堆和技能操作辅助，不实现角色卡、掷骰、HP/MP 记录、命刻等完整游戏客户端功能。
